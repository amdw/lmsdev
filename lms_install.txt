0) Start with LAMP / WAMP PHP, Apache, MySQL stack
   Install composer as per:
   https://getcomposer.org/download/
   PHP memory_limit = 256M
1) Note: look for latest drupal 10 release eg 10.6.2 etc ( Not 11 )
   Install drupal as per
   https://www.drupal.org/project/drupal/releases/10.2.3

   From /var/www/html/
   composer create-project drupal/recommended-project:10.6.2 drupal10

   create MySQL database and user with all permissions granted.

   visit http://localhost/drupal10/web/ in web browser, 
    and follow the instructions

    Choose standard installation profile.

   From /var/www/html/drupal10/web/sites/default
    mkdir files                          [ MIGHT NOT BE NEEDED ]
    mkdir files/translations             [ MIGHT NOT BE NEEDED ]
    cp default.settings.php settings.php [ MIGHT NOT BE NEEDED ]

    I use admin as the Username of the site maintenance account.
   ( and an email address I don't use much or even a non-existant one
     as the site email, so that I can create an ordinary user with my
     own email address )
   Uncheck the "Check for updates automatically"
   Set a site name and slogan

2) Create directories for modules and themes
   cd /var/www/html/drupal10/web/modules
   mkdir contrib
   mkdir custom
   cd /var/www/html/drupal10/web/themes
   mkdir contrib

5) Enable modules in drupal:
   in drupal, go to admin/modules ( Extend )
   in core, enable Password Compatibility
     ( only needed post migration from drupal 7 )
   and, under the Chess section, tick 
     Rating FIDE, Rating List
   This module assumes the existance of a national rating system.
   Choose one if these:
     (i) For ECF League Management, Rating ECF
     (ii) For Chess Scotland League Management, tick Rating Chess Scotland
     (iii) For anything else, tick Rating List Test
   Scroll to the bottom and click install
   
   now, under the Chess section, tick 
     League 
   then choose one of these:
     (i) For ECF League Management, tick: League ECF
     (ii) For Chess Scotland League Management tick: League CS
     (iii) For anything else, tick: Test League Management System
   Scroll to the bottom and click install
   when it asks to enable the required modules, click continue

   Enable:
     Legal
     Generate Password
   ( only needed for the production site )
   Disable:
     Internal Page Cache
        ( because non-logged in users get old versions of pages)

   Add google maps field ( gmap ):
     In Admin, Structure, Organisation:
       Add a simple text field called: Google map
       ( so that it ends up with the machine name field_google_map )
       In manage display, select the format as Google Map from one-line address
       and change the settings, so that the size is 600 x 600

7) Settings for development:
   in drupal, go to admin/config/development/performance
   and disable aggregation of CSS and javascript files
   in drupal, go to admin/config/system/cron
   and set cron to never run
     (this is so it doesn't try to send off rating files)

8) Load Ratings:
   Set up an alias to wherever drush was installed, eg
   alias drush10='/var/www/html/drupal10/vendor/bin/drush'
   and go to /var/www/html/drupal10/web/sites/default
    drush10 status
      to check that drush ( drupal's command shell is working )
    drush10 cr
      to clear the cache so that drush picks up the custom commands 
    drush10 help rll
      to check that the rating list load command has been picked up

   NOTES:
    (a) Some of these may give warning messages the first time you
        save the settings, but they should disappear.
    (b) Do not check anything in Data To Load. These are only needed if
        you want to load ratings via the UI, rather than Drush.

   under admin/config/media/rating_fide:
    Rating system URL : http://ratings.fide.com/download
    Number of players per file 10000
    Number of ratings per file 10000

   depending on the rating option chosen above.
   (i) To load ECF ratings, players and clubs:
   in drupal, go to admin/config/media/rating_ecf
   And set:
    Rating System URL : https://rating-sbox.englishchess.org.uk
    User Name         : LMSTEST
    Password          : 
   Press Save.
   You can load ratings from here, but.
   run:
    drush10 rll ecf
      to load the default ratings (which will be the latest)

   (ii)
   in drupal, go to admin/config/media/rating_cs
   And set:
    Rating System URL :
    Token :
    drush10 rll cs
   (iii)
    drush10 rll test
    Or via the UI into admin/config option Load Ratings and Clubs
    ( copy the file playerDetails.csv into files/rating_test first)

      NOTES:
       1) you might get a file permissions problem at this point.
          On ubuntu linux, I created the directory:
          /var/www/html/drupal10/web/sites/default/files/rating_ecf
          then I changed permissions so that it was owned by www-data
          ( the id under which the web server runs) and that the 
          group owner was my own id. 
          The problem is that this directory needs to be writable by the
          web server for drupal to work, but also writable by the id 
          that is running the command.

       2) CLI php version 8.1 and memory limit 256 needed

     This step needs to be done or else there is no list of clubs.

     Any issues with memory or execution time on the ECF server might be
     fixed by doing: 
       export PHP_OPTIONS='-d memory_limit="356M" -d max_execution_time=250'
     before running drush.

     To load the FIDE ratings:
       drush10 rll fide

       Give unauthenticated and authenticated users the league_view

   Get the code for the Rest UI module:
     composer require 'drupal/restui:^1.21'

     and enable REST UI

   in configuration / web serivces / REST
     set LMS API resources as active and select json.
   in admin/people/permissions:
     grant permission for Access POST on LMS API resource to anonymous users
